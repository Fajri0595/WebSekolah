# Website SMA Negeri Nusantara

Frontend statis (HTML/CSS/JS vanilla) yang terhubung ke backend Google Apps Script sebagai REST API.

- `index.html` — portal publik (SPA)
- `portal/index.html` — login & dashboard Guru/Admin
- `css/style.css`, `js/` — gaya & logika bersama

**Sebelum berfungsi:** isi `GAS_URL` di `js/config.js` dengan URL Web App Apps Script Anda.
Panduan lengkap: `PANDUAN-INSTALASI.md` (dikirim terpisah).
